Before an important project decision (an upgrade, the security posture, an architecture or vendor choice), verify against primary sources (official repository, release notes, docs, advisory databases) and measure where possible; community sources only corroborate. Record sources, access dates and verified data in docs/evaluations/. Operator instruction, 2026-10-03.
